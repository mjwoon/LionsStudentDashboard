# 교과목 유사도 임계값 실험 — 중간보고

**작성일**: 2026-08-14
**대상 논문**: KSC2026 인공지능응용 / 학부생·주니어 논문경진대회
**주제 시스템**: Lions Student Dashboard (전공 적합도 평가 시스템)
**연구 질문**: RQ1 (최적 임계값), RQ2 (임계값 변화의 하위 영향)

---

## 1. 배경 및 문제

교과목 개요를 SBERT(`paraphrase-multilingual-MiniLM-L12-v2`)로 임베딩하고,
코사인 유사도 기준 이상인 과목 쌍을 Neo4j `SIMILAR_TO` 관계로 연결해
"대체 인정"에 활용하는 시스템이다. 규모는 교과목 1,493개, 평가 결과 12,000건(학생 300 × 학과 40).

**핵심 문제 — 임계값 사각지대.** 임계값이 두 곳에서 서로 다르게 설정되어 있다.

- 엣지 생성: 0.8
- 인정 판정: 0.7 (`constants.SIMILARITY_THRESHOLD`)

0.7~0.8 구간은 **인정 기준은 충족하나 그래프에 엣지가 없어 조회 불가**한 사각지대가 된다.
결과적으로 실효 임계값은 사실상 0.8이며, 코드상 0.7은 작동하지 않는다.
두 값 모두 이 도메인(한국어 교과목)에서 실험적으로 검증된 바 없다.

단순 코드 수정으로 끝낼 수 있으나, 임계값이 검증된 적 없다는 점에서 연구 주제로 다룬다.

## 2. 연구 질문

- **RQ1** 한국어 교과목 유사도에서 대체 인정 판정의 최적 임계값 `t*`는?
- **RQ2** 임계값 변화가 학생별 적합도 점수·학과 순위를 얼마나 바꾸는가?
- (RQ3 UI/UX USE 설문은 본 실험 트랙 범위 밖 — 별도 진행)

## 3. 대상 시스템 분석 (코드 확인 결과)

- 유사도는 **프로덕션 하이브리드** `0.7·SBERT + 0.3·TF-IDF`로 계산된다
  (`graphDB/similarity_engine.py`). RQ1 임계값은 이 하이브리드 점수에 적용한다.
- 유효 쌍 규칙: 같은 학수번호 쌍·연계과목(1,2 시리즈) 쌍 제외.
- 평가는 `EvaluationService.batch_evaluate_students`가 DB 기반으로 수행하며,
  유사도·임계값이 주입식으로 전달된다 → **Neo4j 없이 오프라인 재현 가능**.
- 평가 데이터: 고유 학생 300명(학번 기준), 평가대상 학과 40개(라이언스 칼리지 제외).

## 4. 실험 설계

### 4.1 평가셋 (층화 표본, 상위 3구간 전수 + 하위 표본 ≈335쌍)

전체 유효 쌍 1,113,585개(교과목 1,493개)를 유사도 구간별로 층화(시드 고정, `N_k` 기록).
**실측 결과 고유사도 구간이 극히 희박**(≥0.7이 총 115쌍)하여, 하위 3구간은 표본추출하고
**상위 3구간(≥0.7)은 전수 레이블링**한다.

| 구간 | 0.0–0.5 | 0.5–0.6 | 0.6–0.7 | 0.7–0.8 | 0.8–0.9 | 0.9–1.0 |
|---|---|---|---|---|---|---|
| 모집단 `N_k` | 1,100,048 | 6,984 | 634 | 64 | 34 | 17 |
| 표본 | 100 | 60 | 60 | **64 (전수)** | **34 (전수)** | **17 (전수)** |

0.0–0.5는 모집단 대부분을 차지하므로 Recall 추정에 필수. 0.7–0.8은 현행 사각지대로 핵심 관심 구간이며, 전수 레이블링으로 이 구간의 추정 오차를 제거한다.

### 4.2 레이블링 (두 트랙)

판정 문항: *"과목 A를 이수했을 때 과목 B를 대체 인정할 수 있는가?"* (이진)

- **골드 레이블 (주)**: 독립 레이블러 2인이 과목명 + 개요만 보고 판정.
  유사도 비노출, 제시 순서 무작위화(앵커링·적응 편향 차단).
  본 실험은 레이블러를 **LLM(`gpt-4o`) 2회 독립 실행**으로 구성하고,
  사람 2인이 대체·검증할 수 있는 **블라인드 채점표**를 함께 산출 → "LLM 보조 레이블".
  - 레이블러 간 **Cohen's κ**(신뢰도) 보고, κ<0.6이면 기준 구체화 후 재실시
  - 불일치 확정 정책: LLM 트랙은 **보수적 규칙(2회 모두 '인정'일 때만 양성)**, 사람 트랙은 협의
- **은(silver) 레이블 (비교)**: 이름 char n-gram TF-IDF ≥ 0.30 자동 레이블.
  골드 ↔ silver **Cohen's κ**로 값싼 자동 GT의 일치도 정량화.

### 4.3 실험 1 — 임계값 스윕 (RQ1)

t = 0.30~1.00, 0.01 단위로 P/R/F1 산출. 표본 지표를 층별 모집단 비중으로 가중 보정한다.
0.01 해상도를 위해 구간 단위가 아니라 **표본 쌍 단위 Horvitz–Thompson 가중**을 쓴다:

```
w_i = N_k(i) / n_k(i)                       (층 k(i)의 역표집확률 가중치)
TP(t) = Σ_i w_i · [sim_i ≥ t] · [y_i = 1]
FP(t) = Σ_i w_i · [sim_i ≥ t] · [y_i = 0]
FN(t) = Σ_i w_i · [sim_i <  t] · [y_i = 1]
```

부트스트랩 1,000회(층 내 재표집)로 95% 신뢰구간. 산출물: PR 곡선, F1–임계값 곡선, PR-AUC,
최적값 `t*` (LLM 골드·TF-IDF 각각).

### 4.4 실험 2 — 하위 시스템 영향 (RQ2)

추가 레이블링 없이, 임계값 0.6 / 0.7 / 0.8 / t*로 12,000건 전면 재계산
(`EvaluationService`에 유사도·가변 임계값 주입, Neo4j 우회).

- 학과 순위 변동 (Spearman ρ, Top-1 변경 학생 비율)
- 적합도 점수 분포 변화, 등급 이동
- 사각지대(0.7–0.8) 복구 시 추가 인정 관계 수

### 4.5 평가 지표 요약

| 레이블 신뢰도 | 임계값 성능 | 불확실성 | 하위 영향 |
|---|---|---|---|
| Cohen's κ (레이블러 간·골드↔silver) | P / R / F1 / PR-AUC | 부트스트랩 95% CI | Spearman ρ, Top-1 변동률 |

---

## 5. 주요 설계 결정

1. **유사도 = 프로덕션 하이브리드** `0.7·SBERT + 0.3·TF-IDF` (순수 SBERT 아님) —
   실제 `SIMILAR_TO` 엣지를 만드는 점수와 일치.
2. **레이블 = LLM 골드(주) + TF-IDF silver(비교)** 하이브리드 — 지금 end-to-end 실행이 가능하고,
   사람 레이블로 교체 가능한 인프라를 함께 확보. 논문 방어력과 즉시 실행성을 동시에.
3. **RQ2는 Neo4j 우회(주입)** — 완전 재현 가능한 오프라인 재계산.

## 6. 설계 검토에서 발견·정정한 사항

기존 초안(v3)을 검토하며 다음을 바로잡았다.

| 구분 | 초안 | 정정 |
|---|---|---|
| 평가 건수 | 12,120건(학생 303 × 학과 40) | **12,000건(학생 300 × 학과 40)** — 실측 확인 |
| 교과목 수 | 854개 | **1,493개** — `course_all_aggregated.csv`(프로덕션 그래프 정본) 실측 |
| 전체 쌍 수 | 364,231쌍 (= C(854,2)) | **1,113,585쌍** (실측 유효 쌍) |
| 표본 설계 | 층당 60, 총 400쌍 | **상위 3구간 전수(N_k=64/34/17) + 하위 표본**, 총 ≈335쌍 — 고유사도 구간 희박 실측 반영 |
| 가중식 | 구간 단위 `Σ_{구간≥t} N_k·p_k` (0.01 스윕과 모순) | **표본 쌍 단위 HT 가중** (경계에서 기존 식과 일치, 임의 t 일반화) |
| 레이블 방법론 | "레이블러 2인"(사람) 문자 그대로 | **LLM 보조 레이블 + 사람 검증 대체** 구조로 명시, 협의 정책 명문화 |

교과목 수·쌍 수는 파이프라인 실제 실행(RQ1 스모크)에서 산출한 실측값이다. 특히
**대체 인정 판정의 핵심 영역인 ≥0.7 유사 쌍이 총 115개**뿐이어서, 표본이 아닌 전수 레이블링이
가능해졌다(해당 구간 추정 오차 제거).

## 9. 리스크

| 리스크 | 대응 |

| Cohen's κ < 0.6 | 판정 기준 세분화 후 재레이블링, 개정 과정 서술 |
| LLM 레이블 타당성 논란 | 블라인드 채점표로 사람 2인 교체·검증, LLM↔사람 κ 병기 |
