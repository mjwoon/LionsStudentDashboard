# 유사도 임계값 실험 — 실측 결과 (RQ1·RQ2)

**실행일**: 2026-08-18
**대상**: Lions Student Dashboard (KSC2026)
**환경**: RQ1·유사도 = graphDB(py3.11, SBERT), RQ2 재계산 = 루트(py3.12)
**GT**: LLM 골드(gpt-4o, 2회 독립 실행) + TF-IDF silver(비교). 원자료는 `graphDB/results/`(gitignore).

## RQ1 — 최적 임계값

- **표본**: 335쌍 (하위 3구간 표본 100/60/60 + 상위 3구간 전수 64/34/17). 유사도 = 하이브리드 0.7·SBERT+0.3·TF-IDF.
- **레이블러 간 신뢰도 Cohen's κ = 0.859** (거의 완전 일치; 설계 기준 0.6 상회 → LLM 골드 신뢰 가능).
- LLM 양성률 ≈ 20% (pass1 68 / pass2 65 / 335).

| GT | t\* | 95% CI | PR-AUC |
|---|---|---|---|
| **LLM 골드 (주)** | **0.70** | [0.66, 0.79] | 0.45 |
| TF-IDF silver (비교) | 0.43 | [0.40, 0.62] | 0.17 |

- **LLM 골드 ↔ TF-IDF κ = 0.124** (약한 일치). 혼동표 n11=19, n10=40, n01=52, n00=224.
  → TF-IDF 자동 GT는 대체 인정 판단의 약한 대리물임을 실증. 골드(사람/LLM) 전환이 정당함.

**해석**: 최적 임계값 t\* = **0.70**으로, 코드의 인정 판정값(`SIMILARITY_THRESHOLD=0.7`)이 최적이며, **엣지 생성에 쓰인 실효 0.8은 과도하게 엄격**함을 데이터로 확인. 사각지대(0.7–0.8)는 인정되어야 할 쌍을 조회 불가로 만든 것.

## RQ2 — 하위 시스템 영향 (기준선 = 0.8, 12,000건/임계값)

| 임계값 | 인정 관계 수 | 추가(+) vs 0.8 | Spearman ρ (평균/최소) | Top-1 변경률 |
|---|---|---|---|---|
| 0.8 (현행 실효) | 2 | — | 1.000 / 1.000 | 0% |
| **0.7 (t\*)** | 8 | **+6** | 0.999 / 0.925 | **0%** |
| 0.6 | 52 | +50 | 0.999 / 0.925 | 0% |

- **0.6과 0.7의 평가 결과는 완전히 동일**(차이 0쌍) → 영향은 0.7에서 **포화**. 0.6–0.7 구간의 추가 관계 44개는 어떤 학생 평가에도 닿지 않음. **오직 사각지대(0.7–0.8)의 6개 관계만 결과를 바꾼다.**
- 0.8 → 0.7 전환 효과:
  - 점수 변동: **216 / 12,000 쌍(1.8%)**, 평균 Δ +0.035점, 최대 Δ +2.31점.
  - 등급 이동: **C→B 16건** (그 외 전이 없음).
  - 학과 순위: **어느 학생도 Top-1 학과가 바뀌지 않음**(변경률 0%), ρ 평균 0.999.

**해석**: 임계값 사각지대를 바로잡으면(0.8→0.7) 인정 관계 6개가 복구되고 16건이 C→B로 상향되지만, **학생별 최상위 학과 추천은 전혀 바뀌지 않는다.** 즉 이 정정은 **정합성·정확성 개선**이지, 순위를 뒤흔드는 변화는 아니다(현 데이터 기준).

## 종합 결론

1. **RQ1**: 대체 인정 최적 임계값 t\* = 0.70 (κ=0.859로 레이블 신뢰 확보). 코드 이원화(엣지 0.8 / 인정 0.7)에서 **0.7이 옳고 0.8은 과함**.
2. **RQ2**: 0.7로 통일 시 사각지대 6개 관계 복구·16건 등급 상향. 그러나 순위·Top-1은 불변 → **낮은 실무 영향의 정합성 수정**.
3. **권고**: 엣지 생성과 인정 판정 임계값을 **0.7로 일치**시킨다(사각지대 제거). 데이터가 커져 고유사도 쌍이 늘면 영향이 커질 수 있으므로 재평가 여지 명시.
